BEFORE YOU SEND

お問い合わせの前に

同じ不具合がすでに報告されているか確認できますか？

公開されているお問い合わせ一覧をご覧ください。同じ状況の報告があれば、端末や操作手順などの追加情報をコメントできます。

報告後の返信はどこで確認できますか？

投稿したGitHub Issueに調査状況や確認の質問を返信します。GitHubの通知設定に応じて、返信の通知を受け取れます。

ゲームがうまく動きません。何を確認すればよいですか？

配布元で更新がないか確認し、端末とゲームのバージョンを控えてください。続く場合は、発生した画面や操作手順を添えて不具合をご報告ください。データへの影響がわからない場合は、再インストールやデータ削除をせずにお問い合わせください。
