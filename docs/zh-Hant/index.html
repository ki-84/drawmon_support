哪些裝置可以播放？+

你需要一部 iPhone 或 iPad，其運行 iOS 或 iPadOS 27 或更新版本，啟用 Apple Intelligence，並且支援圖像輸入的型號。

我現在可以下載嗎？+

Drawmon正在開發中，並正在準備發布。當它準備好時，App Store的發布日期將會公布。

我必須會畫畫嗎？+

這不是繪畫比賽。形狀、工具和材料有助於傳達你的想法。觀察對手並進行實驗。

圖紙和進度儲存在哪裡？+

該應用程式將您的繪畫和冒險記錄儲存在您的裝置上。它支援自動儲存和三個手動書籤。廣告和購買需要使用網路連線。

支援哪些語言？+

本網站提供16種語言及文字版本。App目前可正常選擇日語和英語，另外14種設定仍處於開發預覽階段。

重新繪製和召喚是如何運作的？+

繪製和重新繪製都是免費的。觀看廣告即可召喚已儲存的夥伴，然後一起重試那個樓層。一次性購買即可移除廣告。
